# CYBERLAB contributor guide

Read docs/CONTRACT.md, docs/DECISIONS.md and PROGRESS.md before changing the project. Keep business logic in domain services, validate inputs, parameterize database access, and keep secrets out of version control. Mark unfinished work TODO(fase-N). Do not add CDN dependencies. Run `make test` and `make lint` after implementation changes. Phase 2's visual direction was approved; Phase 2 is now complete. Implement one project phase at a time.
